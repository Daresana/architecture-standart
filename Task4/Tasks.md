# Задачи реализации

Месяцы отсчитываются от начала проекта. Сроки предварительные. MVP включает онлайн-заявки и передачу ставок в оба кол-центра.

| Код | Система / команда | Крупная задача | Зависимость | Срок |
| :- | :- | :- | :- | :- |
| T1 | Команда трансформации, команды систем, безопасность | Согласовать состав MVP, роли, форматы API, сообщений и CSV. Определить нагрузку, время восстановления, допустимую потерю данных и задержку обновления ставок. | — | М1 |
| T2 | АБС / команда АБС | Создать справочник ставок, загрузку Excel, согласование общих и персональных условий. Настроить права доступа. | T1 | М1–М2 |
| T3 | Инфраструктура / IT | Подготовить Kafka с защитой доступа и копиями сообщений, MS SQL, балансировку и резервный ЦОД. | T1 | М1–М3 |
| T4 | АБС / команда АБС | Создать сервис обмена с Kafka: передача ставок и статусов, получение заявок, ограничение нагрузки и проверка повторов. | T2, Kafka из T3 | М3–М4 |
| T5 | Сервис депозитов / команда интернет-банка | Реализовать заявки, копию ставок, API общих и персональных предложений, статусы и повторную отправку. | T1; T4 для подключения АБС | М2–М4 |
| T6 | СМС-шлюз, телеком-оператор / IT и команда интернет-банка | Согласовать подключение шлюза. Добавить СМС-коды и уведомления. Проверить число попыток и связь кода с условиями заявки. | T1, T5 | М3–М4 |
| T7 | АБС / команда АБС и бэк-офис | Добавить обработку онлайн-заявок, согласование условий, повторное согласие клиента и открытие депозита. | T4, T5 | М4–М5 |
| T8 | Интернет-банк / команда банка | Добавить выбор продукта, счёта и суммы, подтверждение заявки и просмотр статуса. | T5, T6 для завершения | М4–М5 |
| T9 | Сайт / команда сайта | Добавить общие ставки и форму заявки. Подключить сохранение заявки в сервисе депозитов. | T5 | М4–М5 |
| T10 | Кол-центр банка / подрядчик | Добавить приём заявок сайта с проверкой повторов. Подключить получение общих ставок и показ срока действия. Настроить передачу заявок из сервиса депозитов. | T1, T5 | М4–М5 |
| T11 | SFTP / IT | Подготовить сервер обмена и резервирование. Создать отдельные каталоги и учётные записи. | T1 | М2–М3 |
| T12 | Сервис депозитов / команда интернет-банка | Добавить CSV с общими ставками, загрузку на SFTP, повторы и проверку актуальности. | Часть T5 по ставкам, T11 | М4 |
| T13 | Партнёрский кол-центр / партнёр | Настроить получение CSV, загрузку ставок, проверку версии и срока действия. Добавить показ ставок оператору. | T11, T12 | М5 |
| T14 | Все команды, безопасность и поддержка | Проверить полный путь заявки, повторы, нагрузку, отказы АБС и каналов, переключение ЦОД. Подготовить документацию и провести пилот. | T3, T7–T10, T13 | М6 |
| T15 | Все команды | Запустить MVP: онлайн-заявки с обработкой бэк-офисом, заявки сайта и общие ставки у обоих кол-центров. | T14 | Конец М6 |
| T16 | АБС / команда АБС и бизнес | Автоматизировать типовые условия, проверки и открытие. Предусмотреть обработку нестандартных случаев. | T15 | М7–М9 |
| T17 | АБС, интернет-банк, сервис депозитов / команды систем | Запустить автоматическое открытие по подтверждённым заявкам. Для типовых операций в отделении оставить только фронт-офис. | T16 | М10 |
| T18 | Все команды | Проверить автоматическое открытие, доступность и нагрузку. Постепенно расширить запуск. | T17 | М11–М12 |

Справочник и API общих ставок из T5 готовы к концу М3. Остальная часть сервиса — к концу М4.

После согласования форматов API кол-центра, SFTP и загрузка файлов партнёром разрабатываются параллельно. Пилот начинается после проверки полного процесса. Онлайн-оформление кредитов в план не входит.
